# P01b — Personas and User Stories

Personas: tactical coach (formation/XI), sporting director (transfer/renewal), save analyst (reliable CA/PA explorer), editor power user (safe optional write), realism player (no hidden data), scouting analyst (football data charts).

| ID | User story | Requirement |
|---|---|---|
| US-001 | Import compatible save, see source version and completeness | MH-01/05 |
| US-002 | Open player report, inspect eCA, actual CA, strengths and data provenance | MH-02/06 |
| US-003 | Discover best natural position, best new role and training tradeoffs | MH-06/14 |
| US-004 | Review actual match-event radar/heatmap when data exists; honest empty state otherwise | MH-06/18 |
| US-005 | Move attacker to fullback and see consequences for whole XI | MH-07/09/11 |
| US-006 | Compare Best Ability XI and Balanced XI with role conflict explanations | MH-11 |
| US-007 | Evaluate recruit vs existing squad plus cost and alternatives | MH-12/13/25 |
| US-008 | Track 1/3/5-season succession and academy path | MH-14/23 |
| US-009 | Hide all hidden data in Realism Mode, including via AI, rankings, exports | MH-02/24 |
| US-010 | Prepare for opponent using observed information and reversible game plans | MH-16/17 |
| US-011 | Review trends and performance with source, cohort, minutes and timeframe | MH-04/18 |
| US-012 | Future Editor previews CA/PA patch, provides backup, validates, restores | MH-03 |
| US-013 | Navigate without mouse and understand unavailable/partial chart states | All UI |

Acceptance: each story has source contract, failure states, keyboard equivalent, data sufficiency and test fixture. AI explanations must be grounded; editor operations are deferred. See [catalogue](01-full-feature-catalog.md), [design](02-design-system.md).
