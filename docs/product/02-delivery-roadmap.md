# Product Delivery Roadmap — FULL SCOPE (no MVP)

The user explicitly requires **the complete ManagerHub (MH-01..MH-27), without an MVP milestone**. This short page is a navigational summary; the **authoritative, detailed execution plan** is [7-Phase Full Product Plan](../implementation/01-full-delivery-plan.md), with [execution charter](../implementation/00-execution-charter.md) and [ready-to-paste agent prompts](../implementation/02-agent-prompts.md).

| Integration phase | Full deliverable group |
|---|---|
| 1. Foundations, UI, GSAP | Architecture, reusable tokens/components, Liquid Glass shell, motion service, CI and typed contracts |
| 2. Verified Game Data | Safe save import, adapters, snapshots, coverage, player explorer |
| 3. Player Intelligence | Actual CA vs eCA, role/position analysis, full source-backed scouting charts |
| 4. Football Tactics & Squad | Tactical Lab, in/out possession, Role Fit interactions, optimizer, Squad Planner 2.0 |
| 5. Sporting Department | Recruitment, contracts, finances, youth, training and transfer What-if |
| 6. Realistic Club Operations | Matchday/opposition/postmatch, Club DNA, leadership, board, dynasty, AI staff |
| 7. Full Integration & Certified Editing | Set Pieces, optional **verified** save writer, compatibility, all-module QA, packaging/release |

This is a **delivery sequence**, not a separate MVP release or permission to leave fake features. Every module requires real integration, data truthfulness, accessible UI, testing and acceptance. Save editing is restricted to **certified builds**; unknown formats must remain read-only with a clear explanation. No estimated completion date is promised without actual team/fixture evidence.

For visual direction use the Apple-inspired [Liquid Glass & GSAP specification](../implementation/03-liquid-glass-motion-spec.md). For skill selection use the [official animation/skills research](../implementation/04-motion-skills-and-references.md).
