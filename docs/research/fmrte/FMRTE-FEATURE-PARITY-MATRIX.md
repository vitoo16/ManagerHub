# FMRTE Feature Parity Matrix (FMRTE 26 & FMRTE 13 vs ManagerHub)

## 1. Audit Methodology & Evidence Scope

This audit inventories all major functional modules observed in **FMRTE 26 (`26.3.2-build41`)** via `FmrteAvalonia.dll` (`5,850` TypeDefs, `5,280` MemberRefs, `ev_bdf1ea070b38a8c685160958522acf7fce6383af642029c8d8373c25e122580e`, `ev_e217a88c9dcba22182f7d1a06968465d95082861bbae2e9ec167afa2d9d028dd`) and shipped config assets (`config.json`, `Ratings/*.json`, `Presets/*.json`, `english.xml`), cross-referenced against **FMRTE 13 (`13.3.3.62`)** (`26-fmrte13-complete-parity-matrix.md`) and current **ManagerHub** implementation on `feat/classic-editor-record-navigation`.

> [!NOTE]
> Per security and legal governance, licensing/activation (`Fmrte.Licensing`) and live process memory injection (`WriteProcessMemory` / `uAutp`) are **out of scope**. ManagerHub implements **offline `.fm` save decoding and transactional Save-As serialization** with cryptographic HMAC-SHA512 verification.

## 3. Remediation priority (no new native write capabilities)

1. **Existing player, staff, club and stadium editors:** maintain exact-source draft validation, accessible navigation, explicit field scope, undo/redo, checksum and original immutability. Obtain field-specific independent readback and game reload on disposable copies (see the [audit](RCA-WRITER-EVIDENCE-AUDIT.md)).
2. **Player Development:** complete manual A/B, scenario lifecycle and evidence disclosure first; same-scope JSON import and reviewed absolute-target rebase are implemented as candidate scenario lifecycle operations; constrained optimization remains blocked until model fidelity and version evidence warrant it. No auto-CA/PA adjustment.
3. **Safe Save As:** obtain independent field-by-field reload including advance/save/reopen and unrelated-entity diff; retain existing gates.
4. **Read-only parity next:** staff ratings, competition/nation/club extra metadata and verified positional data. Unsupported native writes, transfers, variable-length arrays, freezer or cloning remain research-only, not a claim of complete parity.
