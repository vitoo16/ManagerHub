**2026-10-31 follow-up:** [file-relative native discovery](18-fm2013-file-relative-discovery.md) no longer requires a supplied player address/name/ID. Running FMRTE profile selection, hidden-ability ground truth, full database coverage and writing remain unverified. This supersedes the earlier restart/profile-string gaps.

[The file-source trace](13-fmrte13-stream-source.md) establishes a read-only, address-indexed stream path, without demonstrated `.fm` decoding or file writeback. This is tested research code, not a validated native player adapter.

[Catalog tracing](15-fmrte13-player-catalog.md) follows pointer/list traversal, profile type-marker checks, Player construction and a separate PlayerSID-address dictionary. The later discovery report traces a profile-dependent scan/group preparation path and executes an original anchor-derived scanner. A fixed native global root, complete FMRTE profile resolution and the UI scheduling link remain unresolved.
