# RCA review — native writer evidence audit

Baseline c9f35c9672daa93539b752c302280d1541b498c7, PR #120. This is an evidence correction, not acceptance or expanded write authorization.

Evidence classes:
- **Implementation:** existing editor, draft overlay, parser, fixed-width copy writer, HMAC and validation code.
- **Synthetic roundtrip:** asserts generated bytes can be written and read by the ManagerHub decoder; same decoder is not an independent implementation/game oracle.
- **Real-save read:** reported decode and limited reference comparisons (see 19-fm2013-reference-comparison.md and 25-fm2013-offline-save-decoder.md); these do not prove write correctness.
- **Native runtime acceptance:** exact executable/build and input/output hashes, field-specific independent readback, unrelated-entity comparison, actual game load/advance/save/reopen and recovery. No qualifying receipt was located for the fields below. Prior local CI reports are not that receipt.

No-op byte identity, unchanged source bytes, unrelated unedited synthetic player, mode gate and semantic re-decode are valuable safety tests, not native certification. The static FMRTE write pipeline explicitly records game reload as NOT RUN; a FMRTE live setter is not proof of an offline ManagerHub write. The ledger's corrective-review gate stays in force; all module and phase states stay unchanged. No new writer operation is authorized by this remediation.

For each supported field group produce a private exact-build run on a disposable, backed-up real save: source SHA, executable SHA, exact game build, entity key, before/requested/independent observed value, output SHA, untouched-source proof, unrelated semantic diff, load/advance/save/exit/reopen observation, rollback and reviewer signature. Report missing evidence as missing, not as pass. Never commit the save or licensed binaries.
